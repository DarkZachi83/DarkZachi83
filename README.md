# Hi, I'm Rafał 👋

**Local AI, automation & retro hardware. Building tools I wish I had.**

I build practical, open-source tools – from local LLM helpers to devices that talk to 30-year-old motherboards. Everything gets tested on real hardware before release, and every bug report from users makes it into the test suite.

## 🛠️ Projects

| Project | What it does | Stack |
|---|---|---|
| 🦫 **[AI Bóbr](https://github.com/DarkZachi83/Bobr)** | Checks if a local LLM will fit in your VRAM/RAM – and how fast it'll run – before you download gigabytes. | Python |
| 🐶 **[Niuchacz](https://github.com/DarkZachi83/NIUCHACZ-POST-Code-Sniffer-)** | ESP32 add-on that records the entire POST sequence from a cheap PCI/ISA diagnostic card, with millisecond timing and repair reports. | ESP32, MicroPython, Python |
| 🐭 **[Nornica](https://github.com/DarkZachi83/Nornica)** | Desktop catalogue for retro computer collections: locations, PC builds, QR labels, phone as a scanner. | Python, SQLite |
| 🦡 **[Jaźwiec](https://github.com/DarkZachi83/Jazwiec)** | Create and edit FAT12 floppy images for 86Box, PCem and DOSBox; read and write real floppies via USB drive or Greaseweazle. | Python |

## ⚙️ How I work

- **Stable first.** I build to a working, tested version, release it, then listen to bug reports.
- **Real hardware, real tests.** Automated tests and CI, plus testing on actual motherboards, floppies and GPUs.
- **AI-assisted, human-verified.** I use AI as a pair programmer; architecture, testing and final decisions are mine.
